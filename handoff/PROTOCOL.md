# Codex ⇄ Claude 連絡ルール

このリポジトリでは、Codex（ChatGPT）と Claude がファイルを通して連絡を取り合う。
目的は、カイ（オーナー）の手間を最小にすること。カイを伝書鳩にしない。

## 受信箱

| ファイル | 誰が読む | 誰が書く |
| --- | --- | --- |
| `handoff/to-codex.md` | Codex | Claude（とカイ） |
| `handoff/to-claude.md` | Claude | Codex（とカイ） |

## 作業の流れ（毎回、どんな作業でも最初に）

1. 作業を始める前に、自分の受信箱を読む。`status: open` のメッセージがあれば、それも今回の作業に含める。
2. 処理したメッセージは `status: open` を `status: done` に書き換える。
3. 相手に頼みたいこと・伝えたいことがあれば、相手の受信箱の末尾に追記する。
4. 作業結果をまとめるとき、カイには「受信箱の処理結果」を1〜2行で伝える。

## メッセージの書き方

相手の受信箱の末尾に、次の形で追記する。ID は `日付-連番`。

```
## 2026-10-19-01
- from: claude
- status: open
- re: （返信なら元のID、なければ空）

本文。何をしてほしいか、どこを見ればいいか、終わったら何を返してほしいか。
```

## ルール

- 1メッセージ1用件。長い資料はリポジトリにファイルを置き、パスだけ書く。
- 相手の受信箱は追記のみ。既存メッセージの本文は書き換えない（自分宛ての status 変更は可）。
- `done` が20件を超えたら、古いものを `handoff/archive/` に移してよい。
- 判断に迷うこと（作品の内容・公開・削除など）は相手に頼まず、カイに確認する。
- 秘密情報（パスワード、APIキー、個人情報）は書かない。

## main への反映

相手が読むのは `main` ブランチ。連絡を届けるには、受信箱の変更が main に入る必要がある。
作品やサイトの変更と連絡は、できるだけ別のプルリクエストに分ける（連絡だけ先に届くように）。
